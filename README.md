## Что умеет трекер

### 📦 Автоматический учёт заказов

Трекер самостоятельно фиксирует завершённые рейсы и сохраняет историю работы. Не нужно вручную записывать каждый заказ после его выполнения.

Для каждого рейса сохраняются основные показатели:

- выплата;
- полученный XP;
- время выполнения;
- дата и время заказа;
- статистика текущей рабочей смены.

### 💰 Доход и расходы

На главном экране всегда видно:

- общую выручку;
- расходы;
- чистую прибыль;
- доход в час;
- средний заказ;
- среднее время рейса.

Расходы можно добавлять прямо во время игры с помощью горячих клавиш.

| Комбинация | Действие |
|---|---|
| `Ctrl + 1` | ⛽ Бензин |
| `Ctrl + 2` | 🛡️ Ограбили |
| `Ctrl + 3` | 🔧 Ремонт |
| `Ctrl + 4` | 💳 Штраф / взятка |
| `Ctrl + 5` | ⭐ Потратить XP |

### ⭐ Учёт XP

Можно указать текущий XP персонажа перед началом работы. После этого трекер учитывает опыт, полученный за новые заказы, и показывает XP за смену.

### 📊 Аналитика

История не исчезает после завершения смены. Можно посмотреть результаты предыдущих поездок и оценить эффективность работы по разным периодам.

Трекер помогает понять:

- сколько реально заработано;
- сколько ушло на расходы;
- сколько выполнено заказов;
- насколько быстро выполняются рейсы;
- какой получился фактический доход в час.

### 🖥️ Мини-окно поверх игры

Основные цифры можно оставить поверх GTA5RP и не переключаться постоянно в приложение.

Мини-окно можно настроить под себя, включая прозрачность и положение на экране.

### 🔔 Уведомления поверх игры

Важные события отображаются отдельными компактными уведомлениями поверх игры.

Звук уведомлений можно:

- полностью отключить;
- настроить по громкости;
- проверить непосредственно в настройках.

### 🧾 История заказов

Все записанные заказы доступны отдельным списком. При необходимости ошибочную запись можно удалить, а статистика автоматически пересчитается.

### ⏱️ Рабочие смены

Работу можно разделять на отдельные сессии:

**Начать → Пауза → Продолжить → Завершить**

Это позволяет получать отдельную статистику для каждой игровой смены, а не смешивать все поездки в один общий список.

## Как начать

1. Откройте раздел **Releases**.
2. Скачайте последнюю версию Трекера Дальнобойщика.
3. Запустите приложение.
4. При необходимости укажите текущий XP персонажа.
5. Нажмите **«Начать»**.
6. Запустите GTA5RP и работайте как обычно.

Трекер будет вести журнал рейсов во время игровой сессии.

> Перед первым полноценным использованием рекомендуется выполнить один тестовый заказ и убедиться, что он появился в истории.

---

## Данные

Статистика хранится локально на компьютере пользователя. Удалить всю историю можно из настроек приложения.
