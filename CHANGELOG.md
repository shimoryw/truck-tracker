# История обновлений

- Исправлен перенос названия приложения в боковой панели.

- Уведомления переведены на единый кастомный звук.
- Убран системный звук Windows из уведомлений трекера.
- Кастомный звук теперь учитывает переключатель и выбранную громкость.
- Улучшено отображение подтверждения завершения рабочей смены.
