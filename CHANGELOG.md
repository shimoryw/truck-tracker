# История обновлений

## v0.1.0-alpha.14

- Добавлена автоматическая проверка новых версий через публичные GitHub Releases.
- Добавлена установка обновления из приложения с запуском официального Windows Setup.
- Добавлена проверка SHA-256 релизного файла, когда GitHub предоставляет контрольную сумму.
- Добавлен отдельный блок проекта и поддержки в настройках.
- Добавлены быстрые ссылки на GitHub проекта и Releases.
- Добавлен Telegram-канал разработчика `@shim0ryw`.
- Добавлен контакт разработчика `@shimoryw`.
- Добавлена добровольная поддержка проекта через Telegram-счёт.
- Поддерживаются USDT, TON, SOL, BTC, DOGE, LTC, ETH, BNB, TRX и USDC.
- Добавлен переключатель автоматической проверки обновлений.
- Улучшено оформление раздела настроек.
